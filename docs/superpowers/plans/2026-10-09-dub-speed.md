> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rút thời gian lồng một video ~36 phút (752 câu, lần chạy 53 phút 36 giây) bằng cách đo đúng nút thắt, rồi mới sửa những chỗ đo chứng minh là chậm.

**Architecture:** Dịch local vẫn một request Ollama tại một thời điểm (`qwen3.5:9b-q4_K_M`, context 4096, `think: false` đã có trong payload). Đọc giọng vẫn một Web Worker ONNX, model nạp một lần. **Tech Stack:** Rust (Tauri 2), `ureq`, Ollama tại `http://localhost:11434`, Piper ONNX trong Web Worker (`onnxruntime-web` 1.22.0, `numThreads = 1`), FFmpeg, whisper.cpp. Không thêm crate.

**Spec:** Hội thoại 2026-10-09. Số đo từ `output/I Turned JEV AI Into A 24⧸7 Stock Trader (Full Tutorial) [87q_P6iq9mk]/timing.log` và `lines.json`. Không có spec riêng.

enum DubOp { Translate(usize), Speak(usize), Join }

fn overlap_schedule(batches: usize) -> Vec<DubOp> {
    if batches == 0 {
        return Vec::new();
    }
    let mut ops = vec![DubOp::Translate(0), DubOp::Speak(0)];

    ops.push(DubOp::Join);
    ops
}

            DubOp::Speak(0),
            DubOp::Translate(1),

            DubOp::Speak(1),
            DubOp::Translate(2),
            DubOp::Join,
            DubOp::Speak(2),
            DubOp::Join,
        ]
    );

#[test]
fn pooled_work_never_exceeds_the_limit() {
    use std::sync::atomic::{AtomicUsize, Ordering};
    let live = AtomicUsize::new(0);
    let max = AtomicUsize::new(0);
    let items: Vec<u32> = (0..20).collect();
    run_pooled(&items, 4, |_item| {
        let now = live.fetch_add(1, Ordering::SeqCst) + 1;
        max.fetch_max(now, Ordering::SeqCst);
        std::thread::sleep(std::time::Duration::from_millis(30));
        live.fetch_sub(1, Ordering::SeqCst);
        Ok(())
    })
    .unwrap();
    assert!(max.load(Ordering::SeqCst) <= 4);
    assert!(max.load(Ordering::SeqCst) >= 2);
}
